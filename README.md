# 罗德岛共鸣

面向普通玩家的明日方舟干员性格匹配网站：30 道日常情境题、32 位干员、六个行为维度。非官方同人娱乐项目。

公开站点：https://rhodes-resonance-xun.xun0324.chatgpt.site

## 本地运行

需要 Node.js 22 或更新版本，无第三方运行依赖。

```sh
npm start
```

打开 http://127.0.0.1:4173 。部署产物直接位于 `dist/`，可托管到支持 ES modules 的静态站点服务。

## 体验

- 单题答题、回看修改、跳题补答、浏览器本地自动保存。
- 六维轮廓、保留并列的干员排名、来自实际选择的解释与角色资料来源。
- 32 位干员档案、搜索、原版基础立绘。
- 1080 × 1440 共鸣卡生成、可选代号、图片下载与结果链接分享。

完整答案只保存在本机 localStorage。分享链接的 hash 编码六维总分，不含逐题答案或代号；页面不接入分析 SDK。收到朋友链接时，不会推断对方的具体回答。

## 数据与评分

`content/` 保存 v0.3 内容原稿及审计基准。每个维度五题，每题 0–3 分，原始分 0–15，展示归一化为 `100 × raw / 15`。排名使用整数等价平方距离：

```text
distance = sum((100 × raw[d] - 15 × operator.scores[d])²)
```

距离相同保留并列名次，ID 仅决定稳定展示顺序。解释排除对应干员尚不确定的维度，不足三条时保留实际条数。角色画像是基于选定档案阶段的编辑解读，并非心理量表或官方结论。

编辑 `content/` 后重建并检查：

```sh
node prepare-data.mjs
npm test
```

测试覆盖合法与非法输入、极端得分、顺序不变性、原审计基准、32 位角色可达性、并列、分享编码与解释来源。自动检查不代表已完成真实玩家测试。

## 文件

| 路径 | 用途 |
| --- | --- |
| `dist/app.js` | 路由、答题、本地保存、档案与分享卡 |
| `dist/core.mjs` | 评分、排名、解释与版本化分享编码 |
| `dist/data.json` | 由原稿生成的发布数据 |
| `dist/style.css` | 响应式界面 |
| `dist/assets-manifest.json` | 本地图片、来源与完整性记录 |
| `content/` | 可编辑内容原稿 |
| `tests/core.test.mjs` | Node 内建测试 |
| `.openai/hosting.json` | Sites 托管配置 |
